# Godot Puzzle Projects

This repository contains a collection of puzzle and platformer games developed using the [Godot Engine](https://godotengine.org/). Each project in the repository is structured independently and showcases different gameplay mechanics and development techniques.

## 🎮 Projects

### 1. `2Dgame`
A basic 2D puzzle/platformer game designed to demonstrate simple mechanics using Godot's node system and GDScript.

**Features:**
- Basic character movement
- Level layout using tilemaps
- Interactable elements

### 2. `ctf_quiz`
A Capture The Flag-style quiz game focused on logic and problem-solving questions.

**Features:**
- Question-and-answer system
- Scoring logic
- Potential for multiplayer or competitive play

### 3. `jumper_game`
A simple yet engaging vertical platformer where the player controls a character that jumps between platforms to reach higher levels.

**Features:**
- Platform generation
- Player physics and jump mechanics
- Scoring based on height or distance

## 🛠️ Technologies Used

- [Godot Engine](https://godotengine.org/)
- GDScript
- HTML/CSS/JavaScript (possibly for UI or web integration)
- Roff

  
Each subfolder is a standalone Godot project. Open any of them using the Godot Project Manager.
